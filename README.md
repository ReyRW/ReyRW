## Featured Project

### ⚾ Dodgers Analytics Dashboard

An interactive MLB analytics dashboard built using **Python, Streamlit, and live MLB API data**.

- Analyzes batting, pitching, and team performance
- Uses a Random Forest model to predict Dodgers win probability
- Built with 2023–2026 MLB season data
- Deployed using Streamlit Community Cloud
- Planned expansion to all 30 MLB teams for the 2027 season

🔗 [View Repository](https://github.com/ReyRW/dodgers-analytics-dashboard-project) | [Live Dashboard](https://dodgers-analytics-dashboard-project.streamlit.app/)
